# Skincare routine · Mom

A single-file web app (`index.html`) with a Day, Night and Neutral theme system.
Progress and settings are saved in your browser.

## Publish on GitHub Pages
1. Create a new GitHub repository and upload `index.html` and this README.
2. Go to Settings, then Pages. Under Source choose "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Open the link GitHub shows. On a phone, use Share, then Add to Home Screen.
